# Herdr 终端滚动窗口

2026-11-09 最新决定：Herdr App/TUI 使用单张 AI 卡展示终端文本，尽量用满卡片可用容量；超出时去掉最早的内容，保留最新末尾。不再按 Codex CLI 文字猜测阶段、工具或最终回答，不保留阶段成果历史，不因文本过长续卡。这取代此前 Herdr 的阶段解析要求；Codex 原生 App Server 的结构化阶段卡不变。

## 职责边界

运行适配器只读取选定终端，保留 endpoint/resource/incarnation 身份核验。TUI 读取有界的 recent_unwrapped 内容，以免显示量受当前窗口高度限制；App/core 仍使用只读 screen，不通过滚动应用界面来拼接历史。正文展示不影响原输入回执、原生状态、审批、权限或执行器。

终端展示模块只清理 ANSI/控制字符、转义 Markdown/HTML，并按最终渲染后的 UTF-8 字节预算选择末尾内容。保留文字、命令、提示和换行，不把正文解释为附件动作、链接、复制控件或任务成功证据。卡片状态、合法的停止复制框和固定 IDE 页脚是独立可信区域，先预留其实际大小，剩余容量用于终端窗口。

ChannelTurnTextStream 提供 terminalScreen 替换操作。ChannelTurnPresentation 直接更新当前卡，绕过阶段累积、摘要与续卡；窗口 checkpoint 有界持久化，恢复继续使用原 stream/message ID。已存在的旧阶段 checkpoint 在第一次新画面到达时清除展示历史，保留投递证据；已冻结的最终投递计划继续按原计划恢复。

RuntimeObservationController 在读前后身份复核通过后替换窗口；每次快照替换而非追加，避免重绘重复。断连状态可以叠加提示，但不清掉最后一次有效画面。idle/error/exited 收尾时保留最新窗口，移除停止控件、保留 IDE，仍只占同一张卡；不把终端空闲当成任务成功。关闭 stream 时不发送逐帧普通消息，只交付最终有界窗口。

## 能力及限制

卡片容量采用渠道声明的安全字节预算，不把钉钉短流式字段的 1 KiB 上限当作整个卡片上限；正文走现有静态区域，停止控件/IDE 继续走稳定页脚。底层未返回的历史不会被凭空补齐；此功能是终端窗口，不是无损日志归档。

Codex 原生路径继续按 agentMessage/commandExecution 等事件分区。Herdr 的运行状态报告不等同于正文类型分类，本模块不再进行这种猜测。

App/Core 的 `turn` 是根状态离开 working 的计数，进入 blocked/error 也会增加；TUI 的 `state_change_seq` 与 `completion_seq` 分别描述状态变化及完成转换。它们是结构化状态证据，不能表述成“Herdr 完全没有 turn”。当前两套读取接口均无按这些计数提取某轮正文的参数：TUI 读取最近 512 行，App 读取当前屏幕；两者均可能包含旧问答。观察器传递整段快照，展示层只按容量裁剪末尾，不执行按输入切片或画面差分。本次用户接受保留这一边界，不新增“精准最后一轮”功能。

## 四层检查与 case

- 架构：展示策略与执行、状态和渠道投递正交；Codex 不进入终端窗口策略。
- 模块：App/TUI、任意 agent、快照重绘、滚动覆盖、断连恢复、最终收尾、stream 关闭、身份变化与撤权。
- 函数：UTF-8、中文/emoji、单行超长、转义膨胀、换行/缩进、空画面、预算、checkpoint 恢复；一次观察不重复发卡。
- 静态：新增 checkpoint 字段严格校验，旧状态可读；功能、模块、教程与 case 索引同步。隔离测试不冒充线上验收。
