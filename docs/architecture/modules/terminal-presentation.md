# 终端内容展示

2026-11-08 新增要求：Herdr 的进行中和结束卡不能照搬终端字符画面。保留既有状态、控制文本框及 IDE；阶段成果持续显示，活动窗口有界，命令输出默认收起，超过卡片预算通过公共阶段小结续卡。输入回显、旧任务、终端页脚不能占满卡片。

## 职责及证据

运行适配器继续返回原始只读画面，交接回执和运行状态独立不变。独立的终端展示模块负责去控制字符、识别已知 Codex CLI 画面的输入/助手段/工具段、保守处理未知程序；它不执行指令，不解析附件动作，不决定审批或任务成功。未知格式不猜测阶段或 final，只显示有界正文。

观察器把已稳定的助手段交给公共 phase-progress，当前未稳定段只进入活动窗口。展示去重及当前片段随原观察记录持久化，恢复后不重复阶段；目标/授权读后核验仍在展示前。公共 ChannelTurnPresentation 继续负责阶段续卡和幂等投递。

最终卡保留本次助手内容与已确认展示的阶段，去除旧输入及工具全文。idle/done 只决定结束当前观察卡，状态标题仍是终端空闲，不能声称业务验收通过。只有显式 /history 才读取终端快照详情；收起输出不删除源终端记录。现网 AI 模板没有可用的原生折叠容器，命令以简短摘要显示，详情通过现有 /history 展开查看；不下发未经验证的 HTML details 控件。

## 检查与回归要求

架构层：显示归显示，执行、权限、状态证据、渠道控件独立。模块层：两端、未知 agent、旧历史、输入回显、屏幕重绘、断行、阶段稳定/未稳定、断连恢复、撤权与目标切换。函数层：清理控制序列、识别边界、去重、长度、Markdown/动作注入防护、输出顺序。静态层：功能说明、模块合同、审计 case 映射、模板实际能力一致。

必须验证本次结果不混旧任务；命令原文和输出不进入主卡；稳定成果跨状态刷新/重启保留；未知内容不制造成功结论；历史详情仍是转义显示；超长阶段走公共续卡；IDE 和 /stop 规则不退化。
