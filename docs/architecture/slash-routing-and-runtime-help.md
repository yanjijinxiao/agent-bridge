# 斜杠输入与终端帮助

## 功能合同

用户确认：未注册的 `/xxx` 先给简短文字提示，再按普通消息转发。路径、引用、代码片段和嵌入正文的斜杠不是 Gateway 命令，不给未知命令提示。

1. Gateway 内置名称及别名优先；已安装扩展使用同一注册清单。已注册命令的参数错误、权限不足或运行接口不支持，仍由该命令明确回复，不能降级为终端输入。
2. 未注册名称不创建导航卡、不修改正文；保留空格、换行、附件及原会话目标。提示仅说明按普通消息处理，不声称已接收或已执行。
3. 普通输入仍经过准入、聊天角色、共享范围、绑定代次、合并消息及忙碌策略。未知命令不是绕过这些检查的途径。卡片回调中的过期/未知控制不能变成 agent 输入。
4. 注册查询失败时无法证明输入未注册，不能盲目转发。已经接收或回执不明的输入不重发。原有斜杠收件记录的保守恢复分类保持不变；新的实际输入使用原生/终端输入回执恢复。
5. Codex、Herdr App/TUI 使用同一份命令定义和帮助选择器。`/help` 只显示当前能力可用的常用入口；`/help all` 才是全部内置命令、别名、参数、配置条件和扩展的完整参考。`/help session|input|access|workflow|capabilities` 查看分项，`/help 命令名` 查看单命令；同名冲突使用 `/help /session`、`/help /access` 或 `/help command 名称`。
6. 帮助中的能力说明使用执行端能力描述，区分未适配、需配置和无等价接口。终端画面不称作历史对话，中断不称作任务完成；记录型审批仍指向原请求。Taskboard 未启用时明确说明。
7. 默认页不重复列出 `/leave`、`/session new`、`/project add`、`/ide status`；所有兼容写法继续执行，完整参考说明对应关系。`/follow` 与 `/stream`、Gateway 准入与聊天角色/资源共享仍是不同功能，只调整发现入口，不合并业务权限。
8. `/ide` 是普通入口；身份诊断、兼容确认流程放在单命令帮助，具体授权答复继续由原页面提供。`/follow primary`、未知投递重试属于高级恢复操作。分享机器人、每个人使用自己的 Connector 不要求 `/share`；共享具体会话才使用 `/share`、`/join`。
9. 分项隐藏未启用的 Taskboard/QA 和不支持的新原生操作，完整参考及显式单命令仍说明限制。跟随/展示的状态、关闭及本地默认分支不因开启能力不可用而整体隐藏。审批、提问、待确认输入及原队列记录必须继续可发现，不能因当前后端切换隐藏处理路径；帮助不恢复、回答或重发这些记录。
10. 默认卡片只提供只读导航和分项按钮，不再固定挂载 Taskboard、计划切换或高级操作。正文和按钮使用同一配置/能力选择器。普通语法参考不生成复制控件，文字渠道的实际导航答复由卡片层按需提供。

## 模块职责

- `command-text` / `parseCommand`：只解析语法和别名，不推断授权或变更旧回执分类。
- `channel-command-registry`：统一名称、别名、分项、常用摘要、详细语法及后端语义差异；无 RPC 或状态写入。
- `channel-commands` 的输入分类：从该注册清单确定控制与普通输入；明显路径无需查询扩展，合法扩展别名优先于未知名称提示。原公开导出保留。
- `BridgeService`：控制分支与普通输入共用原有权限、绑定和交接边界；未知名称只增加文字提示。共享访问者不能借扩展命令扩大授权。
- `runtime-command-policy`：实际操作的目标与能力判定。
- `command-help`：统一解析主题、筛选能力/配置、生成正文和只读导航；详见[模块合同](modules/command-help.md)。
- `runtime-help` / `channelHelpText`：仅向共享格式器传入运行描述或原生能力，不再维护两套帮助清单。

## 四层核验范围

本次是针对上述功能的增量检查，不宣称全仓逐行审查完成。

- 架构：命令注册、执行器、权限与恢复责任互不替代。
- 模块：Codex 与 Herdr App/TUI、已绑定/未绑定、共享访问与角色、扩展查询异常、合并/忙碌处理。
- 函数与代码：精确文本、内置/扩展别名、路径/引文误判、失效回调、通知后的异步绑定变化、回执去重。
- 静态与配置：两个教程、兼容性表、模块说明及帮助文本与实际行为一致；不新增连接参数或执行器配置。

历史验证（2026-11-08）：完整回归 3,748 项，3,658 通过、90 项环境条件跳过、0 失败；此数字不是新帮助分层的验证结果。分层改动和检查范围见 [2026-11-12 帮助审查](../audits/2026-11-12-help-levels.md)，不冒称本轮真实 IM/浏览器端到端验收。
