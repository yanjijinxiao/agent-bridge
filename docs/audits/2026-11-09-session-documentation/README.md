元数据及覆盖段落见 [history-coverage.json](history-coverage.json)。本次 U 编号按用户记录顺序产生，不与旧审计 `sourceRecords` 混用。完整聊天和临时抽取物保持本机私有，仓库仅保存脱敏后的要求、范围与来源校验摘要。

旧审计图片范围是 97 个路径中 92 张已读、5 张缺失。本次没有重新逐张打开全部历史图片，不对截图独有内容或现版客户端视觉作新认证。用户提及的其他项目/旅游内容、引用中的旧命令、系统开页通知和单次操作授权不升级为 Gateway 产品需求。
