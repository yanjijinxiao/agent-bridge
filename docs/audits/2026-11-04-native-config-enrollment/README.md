# 原生 IDE 配置与 Connector 自助登记

## 需求与边界（实现前）

用户要求一起调整固定扩展 checkbox 和手工分发 device.token，按架构处理，不取消设备鉴权或改变会话授权。

1. IDE 配置复用 settings.json / JSONC、extensions.json 推荐列表以及导出的 VS Code Profile。取消代码内扩展候选枚举。扩展仍从 code-server 的注册表安装，实际兼容与安装结果单独报告。项目推荐列表本身不自动授权安装；管理页明确保存初始扩展才触发既有准备流程。
2. 保留原来的内部 Profile 数据结构、隔离目录与安装回执，避免仅升级解析器就迁移实例、清空用户扩展或撤销浏览器授权。原生编辑器管理个人设置与扩展；Gateway 的 Profile 是管理员显式选择的初始基线，不读桌面登录态。
3. 新 Connector 只需 Gateway 地址及设备本身的可选运行配置。首次启动生成随机设备 ID 和独立随机凭据，持久化在本机状态目录。Gateway 仅存凭据摘要。秘密不展示、不在 IM 中传递。
4. 新设备在明确启用自助登记的入口建立受限待配对连接。登记前不能发布可使用的 host、执行任务、打开 IDE 或替换现有连接。只有已有个人准入的 IM /connect 和设备本机确认共同通过后，才持久登记并发布授权。
5. 已登记 ID 携带错误凭据不得进入自助登记回退。拒绝、过期、断线、撤权、存储失败均不能变成有效授权。待登记连接有数量、速率和存活时间限制。
6. 旧 nodeId/tokenFile 继续可用且保持原 stateDir 推导，升级不改变原 hostId 和 grants。自动凭据丢失或损坏不可冒用旧身份，须明确重新登记。重连只恢复认证和既有授权，不重放输入、不重复请求原聊天授权。

## 职责

- peer/credentials：本机身份保存、Gateway 设备摘要存储；不负责 IM 准入或会话权限。
- peer/transport：TLS、设备认证、受限连接容量与超时；不自行批准人或设备。
- peer/registry：配对票据、最终来源守卫、设备本机确认、授权持久化及待登记 host 的原子发布。
- peer/index / runtime：配置兼容与依赖组装。
- ide/native-profile：标准文件解析、大小/结构校验及明确的导入范围；不安装扩展或修改实例。
- ide/config / web/ide：验证与编辑初始基线；复用既有 host transport 完成安装和核验。

## 四层核对与预定用例

- 架构：设备认证、个人准入、session 授权分离；原生 IDE 设置与 Gateway 运维配置分离。
- 模块：首次登记、后续重连、旧凭据兼容、已登记 ID 冒用、未配对设备不可见、拒绝/过期/并发/写盘失败、最终来源失效。
- 文件/函数：凭据落盘权限与故障不覆盖；摘要比较；票据单次消费；Profile JSONC 字符串/注释/尾逗号、嵌套配置、非法扩展 ID、禁用项和未知 Profile 内容提示。
- 静态/配置：管理页不再输出扩展 checkbox；导入不立即保存/安装；旧配置无损往返；教程删除手工 token 领取必需步骤，保留真实地址、旧配置说明和认证边界。

实现和测试结果在完成后补充；以上是设计与检查清单，不代表已通过验收。

## 实现与验证

实现已完成。内部 IDE Profile 仍为 settings/extensions，旧配置往返和实例身份不变。原生文件导入仅暂存表单，不会自动保存/安装；导入范围为设置和启用扩展，其他 Profile 段落明确提示。初始扩展核验成功后保存回执，后续保留用户卸载，显式准备才恢复清单。静态 checkbox 和相关 CSS 已删除。

新 Connector 自动保存随机设备身份；Gateway 显式开启 enrollment 才接受受限登记。设备注册前不进入 host 目录；原聊天授权守卫及本机确认通过后才写入摘要和 grant。已知 ID 的错误密钥拒绝，失败登记关闭旧连接以重新获取配对码。旧凭据继续使用原身份和状态目录。

全量回归：3,230 项，3,145 通过、85 条件跳过、0 失败。命名输出见 test-results.jsonl；IDE-08.4 对应 7 项、PEER-01.4 对应 10 项均在该次输出中，校验测试文件摘要相同。typecheck、bridge build、JS 语法、diff whitespace 检查通过。真实 Connector 子进程验证不带 nodeId/tokenFile 启动并在重启后复用本机身份；协议层验证待登记不可见、恶意身份回退、拒绝、撤权、并发、持久化故障和重连。

本轮按架构、模块故障场景、修改函数、静态与配置四层检查两项增量，不声称重新逐行审查整个仓库。85 个跳过的条件测试以及真实第二用户钉钉、手机浏览器、任意第三方扩展实际运行，均不能据此声称完成。线上切换与真实注册表安装结果另记部署回执。
