## 本 session 的持续要求

- Gateway 只有一套完整 App Server 业务接口；桌面与纯 CLI 差异限于连接和部署，不自动换执行器。
- 普通消息运行时 steer；显式 queue 由原生持久化，Gateway 保存来源和回执，未知输入不重发。
- 重启保护 Gateway 自身交接，不把原生任务运行或等待响应变成门禁；恢复订阅并保留原任务。
- 审批/提问发送到原参与者并 @；批准由原生确认后新 AI 卡继续原任务，复制不等于提交或批准。

- 只有必须回填或发送的完整命令/值才提供复制框；解释、路径和目录树不增加复制按钮。
- 进行中、心跳、完成卡的项目 IDE 链接由 Gateway 统一维护；多根项目和原主机身份不能按 cwd 猜测。

- systemError 仅在可靠原生事实和允许条件下恢复，并显示恢复进展；不能通过改显示状态掩盖失败。
