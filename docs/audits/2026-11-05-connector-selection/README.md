## 架构层

- 新增个人目录偏好，身份由已核验的机器人、聊天、用户组成；不以设备名称、项目名或列表位置充当授权。

## 模块与异常层

- ConnectorSelection 管理设备编号、稳定身份和选择代次；Bridge 负责命令及目录范围，RuntimeStateStore 负责持久化。
- 切换清理本人旧项目/会话快照；按钮携带列表版本，复制命令可使用版本。手工 C 编号指最新设备列表。
- 离线、撤权及坏偏好不切换到其他设备。共享资源用户可以选择已有资源，仍不能配对新设备、查询 Gateway 本机或新建任务。
- /new 不复用另一台设备的 cwd 或 sourceThreadId；角色/授权在异步原生读取返回后再次核验。
