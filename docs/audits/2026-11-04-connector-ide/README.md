# Connector 完整 Web IDE 补齐

需求：纯 CLI 主机和桌面主机通过同一 Connector 接入完整 code-server，验证文件编辑、Git、终端、授权和断连恢复。原共享文本页不是完整 IDE，之前的 Linux HTTP 200 也不代表浏览器功能验收。

## 实现前的职责约定

- Gateway 继续使用 WorkspaceIDEManager、IDEAccessServer、个人准入和 90 天浏览器授权；Connector 只增加 IDE 主机传输。原生 Codex App Server 的适配、权限及任务生命周期不改变。
- 设备显式启用完整 IDE，使用设备配置的 code-server；Gateway 不能上传任意可执行路径或任意 TCP/Unix socket 作为代理目标。复用既有本机 IDE 启动、profile、私有 socket 和多根目录生成逻辑。
- 完整 IDE 包含终端，具有运行 Connector 用户的开发权限，不是目录沙箱。仅本人非委托的设备/会话授权可以使用；ide-read、ide-write 委托仍走原共享文本页，不自动升级成执行权限。
- 浏览器身份必须与该账号下该设备的本人授权匹配。每次 HTTP/WS 认证及长连接复核均检查；设备侧独立检查持久授权、会话归属、原生项目根和共享所有权。
- 在现有认证 WSS 上有界传输字节流，不增加第二个执行器，不要求 Connector 开放入站端口。流有数量、块大小、顺序、超时和背压限制；只能连接本连接创建的 IDE lease。
- Gateway/Connector 断连清理 IDE 流和本次 code-server 子进程。已有 Codex 任务继续；浏览器授权和 IDE profile 保留，重连后重新校验并启动 IDE。终端进程不承诺跨此断连存活。

## 四层检查与拟补 case

1. 架构：完整 IDE 与文本共享的权限边界；Gateway、Connector、Codex 三者生命周期；只有一个原生执行入口。
2. 模块：个人浏览器授权→设备授权→原生项目→code-server→WSS 字节流；HTTP/WS、断连重连、撤权、旧 Connector 能力协商。
3. 函数：恶意根、其他 thread/actor/account、过期或委托授权、任意 socket、重复/乱序块、超限、慢接收、半关闭、取消及晚到启动回执。
4. 静态与配置：显式启用、默认不扩权、版本声明、文档、命令输出及用例与实际运行记录对应。

真实验证分别记录：隔离协议测试、Linux CLI + 官方 code-server + 真实浏览器、探探部署路径；手机、其他人/群等未实际操作的组合不冒充通过。

## 新增授权简化要求（实施前）

2026-11-04 用户截图指出每项目重复“选择批准/信任、复制命令”没有必要，要求默认批准并信任目录并简化 connect/access。已确认目标：同一浏览器首次证明本人身份，之后在现有本人资源权限内默认信任当前原生项目；固定链接不携带秘密，不开放匿名访问。设备配对、个人准入和浏览器身份复用同一人，职责仍分离。撤权/到期、不同账号/他人设备、多根变更、重启和旧版迁移需要单独用例。该要求是在完整 IDE 开发期间新增，前述已通过测试不视为覆盖此新流程。

## 已执行的检查与结果

- 架构/模块：设备侧持久 grant、浏览器本人身份、原生项目及根集合逐层核对；测试拒绝其他人、跨账号、委托、任意 socket 和伪造根。Codex 与 IDE 清理边界分别测试，晚到启动 receipt 有独立取消用例。
- 底层函数：乱序/超大/非法编码/EOF 后数据/并发块、64 流上限和 2 MB HTTP/WS 实际传输通过；不是仅检查返回状态。
- 静态/配置：Gateway peer host 不接受 SSH 或任意 binary；设备显式启用；Web UI 保存与旧共享文本兼容；新增 TLS 前端覆盖 HTTP、双向 WebSocket、Cookie 保留与管理 API 拒绝。
- Linux CLI 真实浏览器：4.141.1 官方 code-server，独立原生 CLI 及临时项目，两个 Git 根、终端 cwd、12px/18px 暗色与 Chat 收起、Emacs 编辑保存、Gateway IDE/Connector 重连后输入仍只有一条、撤权拒绝均通过。6 项断言通过，约 120 秒。第一次失败是在工作台外壳已显示而远端 Git 扩展还在初始化时提前断言；改为最多 60 秒等真实仓库出现，未减弱内容断言。
- 用户原链接：远端官方归档摘要/长度校验通过，原项目通过真实管理 API 打开为 running，profile ready；未把本机探测声称为手机验收。
- 授权简化：首次页面一条 trust 确认；跨项目、Origin/CSRF、到期、重启、撤权、legacy/本地 grant 不提升、身份来源一致性、已授权配对后直接展示目录均有 case。

未执行：手机实机、第二位人类跨群、Linux ARM64/Windows 完整工作台。部署结果另记；不能用源代码测试通过宣称已上线。

最终根回归：3198 项，3114 通过、84 条按平台或显式实机开关跳过、0 失败；真实 Linux 浏览器 6 项和真实 Chrome 准备状态 2 项分别执行通过。构建通过。
