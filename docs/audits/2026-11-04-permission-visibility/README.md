# IM 权限展示范围检查

基线 dd43021。用户确认先改权限展示范围；不包含 Connector 一键安装或多用户 Web 管理门户。本轮完成实现和隔离回归，上线状态以单独部署回执为准。

1. 架构：准入、管理员、会话角色、设备配对、浏览器项目权限仍由各自现有服务持有；默认查询限制到本人/当前聊天。Web 管理控制台保留本机管理员边界。
2. 模块：AdmissionService 负责默认个人状态、当前聊天管理和私聊显式全局管理；PeerRegistry 继续按三元身份筛设备；Bridge 提供平台核验身份。
3. 实现：列表、详情、决定与卡片回调必须一致；跨用户、跨聊天、跨机器人、旧卡片及撤权均需用例；只读查看不创建或批准申请，不执行模型任务。
4. 静态与配置：命令帮助和架构/功能文档同步；保留旧持久授权格式、授权有效期和本机管理入口配置。

已验证：普通用户当前聊天的个人/群准入及本人申请，管理员当前聊天与私聊显式全局查看，跨聊天 ID/卡片决定拒绝，跨机器人与撤权拒绝，Connector 首次空列表与三元身份过滤，本机 HTTP 管理与已有授权兼容。IDE 资格直接调用现有 IDEApprovalService，保留个人准入和显式登记的旧 IDE 管理身份；无法核验时不显示为已获准。

新增 7 项用例先在旧实现失败，再在修正后全部通过；其中 /connect 旧行为已有三元隔离，失败点是文案未明确当前聊天，未声称它此前泄露全局设备。首次测试夹具使用非法 UUID 的失败已纠正后重新取得旧实现反例；不计为产品缺陷。相关回归 92 项通过；补充真实 AccountManager 的个人/群/旧 IDE 身份组合后 17 项通过。最终根回归 3178 项：3096 通过、0 失败、82 项按环境条件跳过。类型检查、隔离 TypeScript 构建通过。
