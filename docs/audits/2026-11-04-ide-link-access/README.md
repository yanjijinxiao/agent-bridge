# 2026-11-04 Web IDE 链接直接进入：增量检查

用户明确接受持有链接即可进入，不引入钉钉免登。仅启用头头/探探当前本人已有个人准入来源；其他账号默认策略不变。固定项目 URL 保持原样。此模式使用链接持有权，不声称核实了浏览器访问者身份。

## 四层范围

1. 架构：Gateway 统一处理授权，Connector 只验证已有设备 grant；不增加渠道 OAuth，也不建立第二个 IDE 登录体系。链接访问具有完整开发权限；目录不是操作系统沙箱。
2. 模块：ApprovalService 解析准确个人来源，AccessServer 校验 Origin、浏览器 proof、原生项目和 canonical roots；EndpointManager 撤销变化策略的链接会话并关闭对应长连接，保留个人授权。
3. 函数：一次性交换、固定期限、v4 持久化、禁止转成个人身份、撤销竞态/关开不复活旧 Cookie、设备撤权与项目隔离均有直接断言。
4. 静态/配置：显式配置 source actor 和截止时间；本机管理接口校验当前准入和最长 90 天，默认不开启；管理页保留秒级旧期限，避免无关保存使策略指纹变化。自动进入脚本失败停留可重试，不循环刷新。
